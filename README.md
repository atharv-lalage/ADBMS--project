An incredible full-stack application designed specifically to showcase **Advanced Database Management Systems (ADBMS)** theories physically implemented in a production-like environment. 

This platform leverages the **UCI Online Retail Dataset** to simulate high-throughput transactional flows (**OLTP**), process them through an automated Extract, Transform, Load (**ETL**) script, and generate actionable business intelligence utilizing a Snowflake Schema Data Warehouse (**OLAP**). Machine Learning algorithms are heavily integrated natively into the Application UI.

---

## 🎯 Architecture & Technologies

### 🖥️ Frontend (Vite + React)
A glassmorphic, enterprise-grade Single Page Application (SPA) designed to act as a **Database Operations & Analytics Console**. 
- **Framer Motion**: Leverages complex staggered animations and pseudo-terminal skeleton loaders.
- **Recharts**: D3-powered complex visualizations mapping K-Means Clusters and Linear Regression curves.
- **Session Caching**: Eliminates payload lag globally by synchronizing static API returns onto `sessionStorage`.

### ⚙️ Backend (Flask REST API)
A lightweight Python architectural API acting as the bridge traversing between the dataset cache, Machine learning engines, and the React Client.
- **`scikit-learn` & `mlxtend`**: Embedded memory clusters calculating RFM segmentation (K-Means), Sales predictions, and Market Basket analysis matrices.
- **Memory Optimization**: Employs rapid `pickle` binary dataset caching dropping server restart times algorithmically by over 90%.

### 🗄️ Database Engineering
- **OLTP**: Highly normalized (3NF) relational architecture handling the `users`, `products`, `orders`, and `order_items` transactional inputs.
- **OLAP**: Denormalized Data Warehouse utilizing dimensional models (`dim_date`, `dim_product`, `dim_customer`) connected cleanly to the central `fact_sales` cube to support `Roll-up`, `Drill-down`, `Slice`, and `Dice` mechanisms.
- **Neon DBMS Serverless**: Hosted cleanly on AWS cloud topology.

## 🧠 Core System Modules

### 1. Simulated Transaction Engine (OLTP)
The "Storefront" acts as the origin point simulating high-velocity point-of-sale e-commerce transactions. 
- **Dynamic Apriori Integration**: Scanning items parses the Data Warehouse's Market Basket results to inject live "Frequently Bought Together" recommendations dynamically into the UI alongside products.

### 2. ETL Processing Telemetry 
A visualized log interface showcasing precisely how the pipeline processes the native 500,000+ row dataset:
- Filters 130k+ `NaN` dataset anomalies.
- Disambiguates negative quantity returns.
- Converts scalar pricing across currencies (GBP -> INR).

### 3. OLAP Query Terminal
A fully-built internal pseudo-terminal that demonstrates native SQL compilation running against the Snowflake schema dimensions. Proves Data Warehousing by rapidly extracting `Slices` and `Dices` of subcubes across Product Categories and Geographic distributions.

### 4. Interactive Machine Learning DSS
A beautiful **Decision Support System** routing complex aggregation computations generated by the Appriori, Regression, and Segmentation modules. Admins can visually map high-spend customer targets and **Export Intel** to native `.csv` files locally.

## 🚀 Setup & Execution

### 1. Environment Setup
Clone this repository and ensure Python and Node Package Manager (`npm`) are natively installed.
```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
```

Update your connection string by generating a `.env` file in the root project space:
```env
DATABASE_URL=postgresql://user:password@your-neondb-endpoint.aws.neon.tech/neondb
```

### 2. Backend Execution
Navigate to the `backend` folder and boot up the Flask API processing framework.
```bash
# Switch directory
cd backend

# Install ML and Server requirements
pip install -r requirements.txt

# Run the development server
python app.py
```

*Note: The first execution will take ~10-15 seconds as it compiles the internal `pickle` dataframe caching payload.*

### 3. Frontend Execution
Open a fresh terminal, switch to the `frontend` folder, construct the React node models, and start Vite.
```bash
cd frontend
npm install
npm run dev
```

Visit the designated port URL (usually `http://localhost:5173`) on any native browser.
Login Credentials are: `admin` / `admin`
